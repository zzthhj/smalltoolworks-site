1. 用途

OmniPDF 应用用于帮助您检测、处理、修复、整理和导出 PDF 文件。功能可能包括 PDF 问题检测、批量处理、合并、分割、压缩、旋转、删除或提取页面、OCR 文字识别、加密解密、隐私信息清理、文字脱敏涂黑、文档扫描、照片转 PDF、签名、水印和页码标注等。

OmniPDF 是一个 PDF 处理工具，不提供法律、财务、身份认证、文件认证或官方材料审核服务。

2. 数据隐私

PDF、OCR 文字、密码和签名在设备上处理，不上传给我们。最近文件功能可保存本地副本及文件名称、路径、页数和大小。清空最近文件会删除由 App 管理的副本，外部导出文件由你管理。

2.1 匿名产品分析

OmniPDF 使用 Aptabase 收集有限的匿名分析数据，以了解功能使用情况并改进 App。数据可能包括 App 启动、主要入口点击、工具标识符、完成或取消结果、粗略的文件数量与耗时区间、导出操作、付费页面交互，以及匿名的购买方案和购买结果事件。

Aptabase 可能自动附带临时会话标识符、时间戳、语言、操作系统名称与版本、App 版本与构建号、SDK 版本、设备型号及 Debug/Release 状态。Aptabase 可能临时处理接收网络请求所需的 IP 地址和 User-Agent。OmniPDF 不会发送文件名、路径、文档内容、OCR 文字、密码、签名、自由输入文字、精确文件大小、精确页数、Apple ID、广告标识符或持久设备标识符。

Aptabase 会利用 IP 地址和 User-Agent 生成粗略地区及每日变化的假名化标识符。分析数据会在 Aptabase 的欧盟区域处理和存储，最长可能保留五年。数据不会与你的身份关联，也不会用于跨 App 或跨网站追踪、广告、用户画像、与数据经纪商共享或出售。详见 Aptabase 隐私政策。OmniPDF 不含广告，也不要求注册或登录。

3. 文件、相册与相机

OmniPDF 仅在需要时请求相关权限，用于：

  • 从「文件」导入 PDF、图片或文档；
  • 从相册选择照片；
  • 使用设备相机扫描文档；
  • 在您主动操作时，将处理结果保存到「文件」或相册。

这些权限仅用于您在 App 内主动使用的功能。

4. PDF 处理

所有 PDF 检测、修复、压缩、OCR、批量处理、脱敏涂黑、加密解密、页面编辑、签名、水印和导出操作，均在您的设备本地完成。

如果您使用 OCR 功能，识别出的文字仅在设备本地生成，不会发送给我们。

如果您使用密码相关功能，密码仅在本地用于打开、加密或解密您选择的 PDF 文件。我们不会获取或存储您的密码。

5. 导出文件与元数据

导出文件时，OmniPDF 会根据您选择的操作生成新的处理结果。根据您使用的工具，OmniPDF 可能会移除或修改文档元数据、注解、可编辑内容、附件或其他 PDF 附加信息。

如果您使用文字脱敏或隐私清理功能，请在分享前预览导出结果，确认处理效果符合您的需要。

6. 应用内购买

可选购买、保存次数、订阅或付费导出由 Apple 处理。我们不会获取您的银行卡、账单信息或 Apple ID 详情。
