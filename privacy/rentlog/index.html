1. Overview

RentLog is a landlord record-keeping tool. Rental business data you enter — properties, tenants, leases, payments, photos, and PDFs — is stored on your device. We do not operate a cloud account for that data and do not automatically sync it to our servers.

2. Local Storage and Backups

All property, tenant, financial, photo, and PDF records stay on your device unless you export them. Backup & Restore and tenant-archive export run only when you start them. You choose where those files go. We cannot read your backups.

3. Anonymous Usage Statistics

To improve the product, RentLog records anonymous feature-use and purchase-funnel events through the third-party service Aptabase — for example which tool you used, a duration range, whether the paywall was opened, or whether a purchase completed. Events use only fixed options and time ranges. They do not include rental records, document contents, personal identity, or a device identifier. If you install after tapping an App Store ad, Apple’s official attribution interface may return source details such as the ad keyword and country, used only to understand ad performance. None of these statistics can be linked to you. You can disable reporting by restricting the app’s network access in system settings.

4. Device Permissions

Camera, Photo Library, and Face ID / Touch ID (if you enable them) are used only on-device for inspections, imports, and unlocking the app.

5. No Account, No In-App Ads

You do not need an account. RentLog shows no third-party advertisements inside the app.
