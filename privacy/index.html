This website

smalltoolworks.com serves static pages and uses a Cloudflare Pages Function to redirect App Store links to a regional storefront. The function uses the country supplied by Cloudflare; it does not create an account or store a user profile. It sets no cookies, runs no analytics or advertising scripts, loads no third-party JavaScript and embeds no trackers. There is no consent banner because there is no optional tracking script to control.

Fonts are served from your own system, and images are plain files on this same domain. Our hosting provider, Cloudflare, may process your IP address, browser information and request logs to deliver and protect the site. See the Cloudflare privacy policy.
