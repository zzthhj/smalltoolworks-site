1. Finalidad

CareerShot está diseñado para crear retratos profesionales y fotos de perfil a partir de fotos que el usuario captura o selecciona.

2. Resumen del procesamiento de datos

CareerShot procesa imágenes principalmente en el dispositivo. No operamos un flujo en la nube para subir fotos o datos de análisis facial.

3. Datos faciales (Face Data)

Para ofrecer funciones de edición de retrato, CareerShot puede procesar en el dispositivo datos faciales de fotos seleccionadas por el usuario, incluyendo:

  • cuadro delimitador facial
  • puntos de referencia faciales (por ejemplo, contornos de ojos/labios/mentón)
  • información de ángulo/pose facial (para controles de calidad)

CareerShot no utiliza datos faciales para verificación de identidad, perfilado de usuarios ni publicidad.

4. Cómo se usan los datos faciales

El procesamiento facial se utiliza únicamente para:

  • verificar si hay un rostro frontal válido de una sola persona
  • mejorar el recorte/composición del retrato
  • mejorar la calidad de renderizado/alineación del retrato (como ajuste de retrato y vestimenta)

5. Compartición y divulgación

No vendemos, compartimos ni divulgamos datos faciales a terceros.
Los metadatos de análisis facial no se transmiten a nuestros servidores.

6. Almacenamiento y retención

  • Los metadatos de análisis facial son datos temporales de procesamiento y no se conservan como un perfil biométrico independiente.
  • Los metadatos temporales se descartan tras el procesamiento.
  • Las fotos editadas finales solo se guardan cuando el usuario elige explícitamente guardar/exportar (por ejemplo, en Fotos).

7. Permisos de Cámara y Fototeca

  • Acceso a Cámara: para capturar fotos para edición (por ejemplo, reemplazo de fondo y mejora de retrato).
  • Acceso a Fototeca: para seleccionar fotos y guardar imágenes exportadas.
  • El procesamiento se realiza en el dispositivo.
