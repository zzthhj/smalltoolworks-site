1. 用途

OmniPDF 應用用於協助您檢測、處理、修復、整理和匯出 PDF 檔案。功能可能包括 PDF 問題檢測、批次處理、合併、分割、壓縮、旋轉、刪除或擷取頁面、OCR 文字辨識、加密解密、隱私資訊清理、文字脫敏塗黑、文件掃描、照片轉 PDF、簽名、浮水印和頁碼標註等。

OmniPDF 是一款 PDF 處理工具，不提供法律、財務、身分認證、文件認證或官方文件審核服務。

2. 數據隱私

PDF、OCR 文字、密碼與簽名在裝置上處理，不上傳給我們。最近檔案功能可儲存本機副本及檔案名稱、路徑、頁數和大小。清空最近檔案會刪除由 App 管理的副本，外部匯出檔案由你管理。

2.1 匿名產品分析

OmniPDF 使用 Aptabase 收集有限的匿名分析資料，以了解功能使用情況並改善 App。資料可能包括 App 啟動、主要入口點擊、工具識別碼、完成或取消結果、概略的檔案數量與耗時區間、匯出操作、付費頁互動，以及匿名的購買方案和購買結果事件。

Aptabase 可能自動附帶臨時工作階段識別碼、時間戳記、語言、作業系統名稱與版本、App 版本與組建編號、SDK 版本、裝置型號及 Debug/Release 狀態。Aptabase 可能暫時處理接收網路請求所需的 IP 位址和 User-Agent。OmniPDF 不會傳送檔案名稱、路徑、文件內容、OCR 文字、密碼、簽名、自由輸入文字、精確檔案大小、精確頁數、Apple ID、廣告識別碼或永久裝置識別碼。

Aptabase 會利用 IP 位址和 User-Agent 產生概略地區及每日變更的假名識別碼。分析資料會在 Aptabase 的歐盟區域處理及儲存，最長可能保留五年。資料不會與您的身分關聯，也不會用於跨 App 或跨網站追蹤、廣告、建立個人檔案、分享給資料仲介或出售。詳見 Aptabase 私隱政策。OmniPDF 不含廣告，亦毋須註冊或登入。

3. 檔案、相簿與相機

OmniPDF 僅在需要時請求相關權限，用於：

  • 從「檔案」匯入 PDF、圖片或文件；
  • 從相簿選擇照片；
  • 使用裝置相機掃描文件；
  • 在您主動操作時，將處理結果儲存到「檔案」或相簿。

這些權限僅用於您在 App 內主動使用的功能。

4. PDF 處理

所有 PDF 檢測、修復、壓縮、OCR、批次處理、脫敏塗黑、加密解密、頁面編輯、簽名、浮水印和匯出操作，均在您的裝置本機完成。

如果您使用 OCR 功能，辨識出的文字僅在裝置本機產生，不會傳送給我們。

如果您使用密碼相關功能，密碼僅在本機用於開啟、加密或解密您選擇的 PDF 檔案。我們不會取得或儲存您的密碼。

5. 匯出檔案與元數據

匯出檔案時，OmniPDF 會根據您選擇的操作產生新的處理結果。根據您使用的工具，OmniPDF 可能會移除或修改文件元數據、註解、可編輯內容、附件或其他 PDF 附加資訊。

如果您使用文字脫敏或隱私清理功能，請在分享前預覽匯出結果，確認處理效果符合您的需要。

6. App 內購買

可選購買、保存次數、訂閱或付費匯出由 Apple 處理。我們不會取得您的付款卡、帳單資訊或 Apple ID 詳情。
