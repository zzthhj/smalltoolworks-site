1. 概述

RentLog 是房東紀錄工具。你輸入的出租業務資料預設保存在本機。我們不為這些資料提供雲端帳號，也不會自動同步到我們的伺服器。

2. 本機儲存與備份

除非你主動匯出，房產、租客、財務、照片和 PDF 都留在裝置上。備份／還原與租期檔案僅在你操作時產生。

3. 匿名使用統計

為改進產品，RentLog 會透過第三方服務 Aptabase 記錄匿名的功能使用與購買漏斗事件，例如使用了哪個工具、使用時長區間、是否打開付費牆或完成購買。這些事件只包含固定選項和時間段，不包含房產、租客、文書內容、個人身分資訊或裝置識別。若您點擊了 App Store 廣告後安裝，蘋果官方歸因介面會返回廣告關鍵詞與國家等來源資訊，用於了解廣告效果。所有統計均無法關聯到您個人。您可以在系統設定中限制網路存取來停用統計上報。

4. 裝置權限

相機、相簿、Face ID / Touch ID（如開啟）僅在本機使用。

5. 無需帳號，App 內無第三方廣告

無需註冊。RentLog App 內不展示第三方廣告。
