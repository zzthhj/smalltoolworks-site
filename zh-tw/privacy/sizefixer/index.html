1. 私隱概要

SizeFixer（「本 App」）用於為上傳準備相片：壓縮檔案大小、轉換格式、調整尺寸。所有相片處理均在您的裝置上完成。

為了完善產品並更好地服務大家，本 App 會傳送有限的產品互動分析資料。相片與影像內容絕不會離開您的裝置。

2. 相簿與本機資料

相簿和檔案存取權限僅用於：

  • 從相簿選擇相片或從「檔案」匯入圖片；
  • 在您主動操作時，將處理結果儲存到檔案或相簿。

所有壓縮、轉換、調整尺寸與裁切均在本機完成。您的相片絕不會上傳到我們的伺服器。

遮蔽人臉功能使用 Apple 的 Vision 框架，完全在您的裝置上偵測人臉位置，以便在其上繪製遮蔽方塊。人臉資料與偵測結果不會被儲存或傳送。

3. 匯出檔案

匯出時，SizeFixer 可能會移除輸出檔案中的隱藏中繼資料，如 GPS、相機 EXIF 資訊。僅您選擇儲存的影像資料會寫入裝置。

4. 有限的使用分析

我們使用注重私隱的 Aptabase 分析服務。可能記錄 App 啟動、您使用的功能、匯入的項目數量、一次處理或匯出是否成功、付費牆互動，以及購買與恢復的結果。

我們不會傳送相片、影像內容、檔案名稱、影像中辨識出的文字、條碼或二維碼內容、姓名、電郵、裝置廣告識別碼（如 IDFA）或自由輸入文字。

Aptabase SDK 可能附帶臨時工作階段識別碼、App 和系統版本、裝置型號、語言/地區等基本技術資料。其服務會暫時處理 IP 位址和 User-Agent，用於產生粗略地區及每日變化的假名識別碼。分析資料在 Aptabase 歐盟區域處理，最長可能保留五年。詳見 Aptabase 私隱政策。

若您點擊 App Store 廣告後安裝本 App，蘋果官方歸因介面會傳回廣告系列、關鍵字與國家或地區等來源資訊。我們會將這些匿名編號與購買事件一起記錄，僅用於了解廣告效果；所有統計均無法關聯到您個人。

5. 廣告、追蹤與帳戶

本 App 不含廣告，不向廣告網絡分享資料，亦不會跨其他公司的 App 或網站追蹤您。使用本 App 毋須註冊或登入。

6. App 內購買

可選的保存次數與訂閱由 Apple 處理。我們不會取得您的信用卡或 Apple ID 資訊，僅接收解鎖功能所需的購買狀態，以及方案類別和購買結果等有限分析資料。

本機處理與儲存

圖片編輯與人臉遮蔽偵測在本機完成。中繼資料會依工具需要讀取或移除，不用於產品分析。匯出的圖片由你保管。

有限的產品分析

使用 Aptabase 的 App 會自動傳送有限的功能使用、匯出與購買結果事件，並可能包含暫時工作階段識別碼、時間戳記、裝置型號、語言、系統與 App 版本。服務會處理接收請求所需的 IP 位址和 User-Agent，用於概略地區及每日變更的假名識別碼。照片與文件內容不會用於這些統計。

Aptabase 的政策說明分析資料最長可能保留五年。沒有持久個人識別碼時，可能無法找出並刪除某位使用者的事件。
