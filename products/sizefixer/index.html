SizeFixer

One place for everyday photo fixes.

Resize, compress, convert and clean up photos in one place. Fast, local and batch-friendly image utilities — built for the fifteen seconds between "this file is too big" and "sent".

iPhone & iPad On-device processing Batch workflows
Core tools

Everything an ordinary photo actually needs

No editor's timeline, no filters, no canvas. Just the adjustments that come up in real tasks.

Compression

Reduce file size so photos fit an upload limit, an email, or a message.

Format conversion

Convert between HEIC, WebP, JPG and PNG.

Exact resizing

Set precise width and height in pixels, or lock to a target aspect ratio.

Crop

Frame the part of the photo you want, using fixed ratios when needed.

Rotate & flip

Correct orientation and mirror an image without leaving the app.

Borders

Add a clean border or margin when a photo needs to sit inside a layout.

Watermark

Apply text or image watermarks before sharing a photo publicly.

Metadata removal

Strip embedded location, device and capture information before you share.

Redaction

Detect and obscure faces and sensitive detail in a photo.

Background tools

Remove or adjust the background of a photo.

Batch

When it is a folder, not a photo

Apply one configuration across many images and export them together.

Batch processing

Select several photos and apply the same resize, compression, conversion or redaction steps to all of them in one pass.

Consistent output

Use one preset across the batch so every exported image matches the same dimensions, format and quality settings.

Privacy

Your photos are processed on your device

Image adjustments happen locally wherever the task allows it. Your photos are not uploaded to a server to be edited.

Redaction is on-device

Face detection for redaction runs on your device using on-device framework APIs. Photos and detected face data are not uploaded.

Metadata stays yours

Metadata removal strips location and device data from exported files, and nothing else is added back.

No account required

SizeFixer does not require sign-in or a profile to process images.
