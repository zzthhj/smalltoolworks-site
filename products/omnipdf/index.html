OmniPDF

Free PDF repair and cleanup. No subscription.

Fix PDF problems. Check, repair, clean and optimize documents without a subscription. OmniPDF detects what is wrong with a PDF — wrong page orientation, blank pages, oversized files, leftover annotations — and fixes it in one pass.

View OmniPDF on the US App Store China mainland App Store Get support

Page language does not decide your App Store account region. Choose an available storefront; Apple may redirect based on region.

iPhone & iPad Local processing where possible No subscription
How OmniPDF is free All PDF tools are free to use. A short ad may be shown when exporting a processed document. There is no subscription, no trial countdown and no paywall on the repair tools themselves.
Detect

Find out what is actually wrong

Run a check before you touch anything. OmniPDF reports the issues it finds so you can decide what to fix.

Page orientation

Find pages that are rotated, skewed or saved with the wrong orientation.

Blank pages

Detect empty pages that add nothing but file size and printing ink.

Oversized files

Identify documents that are larger than they need to be for their content.

Password protection

Check whether a document is encrypted or locked before you attempt repairs.

Annotations

List leftover comments, highlights and markup left in the document.

Forms

Review interactive form fields and flag documents that still contain them.

Metadata

Surface author, creator, producer and other embedded document properties.

Searchability

Check whether text is real text or only a scanned image, which affects search.

Fix

Repair with a single workflow

Instead of fixing one problem at a time, apply the fixes a document needs in one pass.

Correct page orientation

Put rotated or sideways pages back the right way up without re-printing or re-scanning the document.

Remove blank pages

Drop empty pages that break printing, inflate file size and make a document harder to read.

Optimize file size

Reduce oversized documents to something practical for email, messaging and everyday uploading.

Clean annotations

Strip leftover comments, highlights and review markup that should not travel with the final file.

Remove metadata

Clear embedded document properties before sharing a file you do not want to describe in detail.

Apply multiple fixes at once

Combine orientation, blank-page, size, annotation and metadata cleanup into a single repeatable workflow.

Batch

When one document is not the whole job

Contracts, receipts, scanned batches — most PDF problems arrive in piles, not singly.

Process multiple PDFs

Apply the same checks and repairs across a group of documents rather than opening each one by hand.

Consistent repair workflows

Reuse the same repair configuration so every document in a batch comes out consistent.

Export results together

Finish a batch in one go instead of exporting and re-handling each file separately.

Local whenever possible

Files are processed locally on your device wherever the task allows it, so your documents stay with you.

No account required

OmniPDF does not ask you to create an account or sign in to use the PDF tools.

Transparent advertising

A short ad may appear when exporting. Details are covered in the OmniPDF privacy policy.

Not every operation can run entirely on-device. What is transmitted, and why, is described plainly in the OmniPDF privacy policy.
