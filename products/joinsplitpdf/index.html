JoinSplit PDF

Merge PDFs, split selected pages and organize documents on your device.

Get JoinSplit PDF on the App StoreGet support

Merge, split and organize

  • Merge PDFs Add files, change their order and combine them into one PDF. Add more files while sorting, then preview before exporting.
  • Split your way Create one file per page or split by a fixed page count. Select nonconsecutive pages to build separate PDFs, exporting only what you choose.
  • Organize pages Reorder, rotate, crop, delete or duplicate pages. Replace pages, insert blank pages, and undo or redo changes.
  • Check before exporting Preview results, name files, keep original page sizes or use A4, A5 or Letter. Set an opening password for exported PDFs and bundle multiple results as a ZIP.

Pay as needed, without a subscription

Editing and preview are free. Save or share using a single credit, or buy Lifetime for unlimited exports. One credit covers all output files in the current task and is used only after a successful save or share. Exporting the same task again does not use another credit.

On-device processing

PDF contents are not uploaded and original files stay unchanged. Save a task copy and return to editing later.
