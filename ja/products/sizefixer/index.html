私たちのアプリ

SizeFixer

日常の写真処理を、一つのアプリで。

圧縮、変換、サイズ調整、写真の整理を一か所で。速く、端末内で、一括にも向きます。「大きすぎて送れない」から「送信できた」までの十数秒のために作りました。

App Store で入手 サポート

世界中の App Store で配信しています。

iPhone と iPad 端末内で処理 一括処理に対応
主なツール

ふだんの写真に本当に必要なもの

タイムラインも、フィルターも、キャンバスもありません。実際の作業で使う調整だけです。

圧縮

アップロード制限、メール、メッセージに収まる大きさまで写真を下げます。

形式の変換

HEIC、WebP、JPG、PNG のあいだで変換します。

正確な寸法

幅と高さをピクセルで指定するか、目的の縦横比に固定します。

切り抜き

必要な範囲を切り抜きます。よく使う固定比率にも対応します。

回転と反転

向きの修正や鏡像を、アプリを離れずに行います。

枠

レイアウトに入れる写真へ、すっきりした枠や余白を足します。

透かし

共有する前に、文字や画像の透かしを入れます。

メタデータの削除

共有する前に、位置、端末、撮影情報を消します。

マスキング

写真の顔や見せたくない部分を検出して隠します。

背景ツール

写真の背景を除く、または調整します。

一括

一枚ではなく、フォルダごと処理するとき

同じ設定で複数の写真を処理し、まとめて書き出します。

一括処理

複数の写真を選び、同じ拡大縮小、圧縮、変換、マスキングを一度で適用します。

出力を揃える

同じプリセットを一括に使い、書き出す写真の寸法、形式、品質を揃えます。

プライバシー

写真は端末の中で処理されます

作業が許す限り、画像処理は端末内で完了します。編集のために写真をサーバーへ送ることはありません。

マスキングは端末内

マスキング用の顔検出は端末のフレームワーク API で実行し、写真と検出した顔データは送信しません。

メタデータはあなたのまま

必要に応じてメタデータを読み取り・削除しますが、利用分析には送りません。書き出した画像はお客様が管理します。

アカウント不要

画像の処理にログインやプロフィールは不要です。
