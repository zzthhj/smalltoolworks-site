プライバシーポリシー全文

最終更新：2026年9月5日

  1. 用途： SeeClear は色の見分けを助けるアプリです。色認識、色の見やすさ改善、写真スコア、コーデ配色などを提供します。

  2. データの取り扱い： 写真やファイルは端末内で処理され、アプリは内容や設定を端末に保存する場合があります。限定的な利用分析、該当する Apple インストール計測、購入には通信を利用する場合があります。詳細は以下の補足をご確認ください。

  3. 匿名の利用統計： 製品改善のため、第三者サービス Aptabase （EU）経由で、開いた機能、結果の有無、滞在時間の区間、ペイウォール表示、購入完了など、固定の選択肢と時間区間のみを記録します。写真、具体的な色、校正の回答、身分情報、広告IDは含めません。App Store 広告をタップしてインストールした場合、Apple の公式アトリビューション API がキーワード番号や国などの出典を返すことがあり、広告効果の把握に使います。 分析イベントに写真やファイルの内容は含まれません。技術的なリクエスト情報と一時的な識別子については以下の補足をご確認ください。

  4. 端末内データ： 写真、カメラ、認識、改善、スコア、コーデ分析は端末内で処理します。設定、無料回数、Pro 状態も端末に保存します。

写真や結果はサーバーに上げません。 アカウント登録は不要です。 アプリ外の行動は追跡しません。 アプリ内課金は Apple が処理し、カード番号や請求先は受け取りません。

  1. カメラ・写真・触覚： カメラ、写真ライブラリ、任意の触覚フィードバックを使うことがあります。いずれも端末内です。権限は iOS 設定で管理できます。

  2. 医療目的ではありません： 医療アドバイス、診断、治療は行いません。色認識と校正は本アプリの設定用です。

  3. サポート： rtx3070757@gmail.com

データ処理に関する補足

端末内の処理と保存

カメラ映像、色認識、画像分析、詳細結果は端末上で処理します。保存した写真、色、分析記録、設定、使用回数は、削除またはアンインストールまで端末内に残る場合があります。

限定的な利用分析

Aptabase を使用するアプリは、機能の利用、書き出し、購入結果などの限定的なイベントを自動送信します。一時的なセッション ID、日時、端末モデル、言語、OS とアプリのバージョンなどが含まれる場合があります。サービスは通信に必要な IP アドレスと User-Agent を処理し、おおまかな地域と毎日変わる仮名識別子を算出します。写真や書類の内容は分析に含まれません。

Aptabase のポリシーでは、分析データは最長 5 年間保存される場合があります。永続的な個人識別子がないため、特定の利用者のイベントを探して削除できない場合があります。

Aptabase · プライバシーポリシー

このアプリは Apple AdServices で App Store 広告からのインストール元を取得します。キャンペーン、キーワード ID、国や地域などの限定的な情報を利用分析に用います。写真は送信しません。

SeeClear の現在のコードは、色覚調整の結果と適用した補助モードの定型分類も送信します。各設問の回答や認識した具体的な色は送信しません。

アプリ内購入は Apple が処理します。カード情報や Apple ID は当方に送信されません。サポートへのメールには、メールアドレス、本文、お客様が選んだ添付ファイルが含まれます。

SeeClear は日常の補助専用です。医療診断、信号の判断、安全上重要な用途には使用しないでください。重要な色の情報は別の方法でも確認してください。
