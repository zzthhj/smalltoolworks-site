1. 用途

OmniPDF は、PDF ファイルの検出、処理、修正、整理、書き出しを行うためのアプリです。PDF の問題検出、一括処理、結合、分割、圧縮、回転、ページの削除または抽出、OCR 文字認識、暗号化と解除、プライバシー情報の削除、テキストの黒塗り、文書スキャン、写真から PDF への変換、署名、透かし、ページ番号の追加などの機能を含む場合があります。

OmniPDF は PDF 処理ツールです。法律、金融、本人確認、証明、または公式な書類審査サービスを提供するものではありません。

2. プライバシー

PDF、OCR テキスト、パスワード、署名は端末上で処理し、当方には送信しません。最近使ったファイルは、ローカルコピーと名前・パス・ページ数・サイズを保存する場合があります。履歴の消去で管理対象のコピーを削除します。外部に書き出したファイルは別に管理してください。

2.1 匿名の製品分析

OmniPDF は、機能の利用状況を把握してアプリを改善するため、Aptabase を使用して限定的な匿名分析データを収集します。これには、アプリの起動、主要な入口のタップ、ツール識別子、完了またはキャンセル結果、ファイル数と処理時間のおおまかな範囲、書き出し操作、購入画面での操作、匿名の購入プランおよび購入結果イベントが含まれる場合があります。

Aptabase は、一時的なセッション識別子、タイムスタンプ、言語、OS 名とバージョン、アプリのバージョンとビルド番号、SDK バージョン、端末モデル、Debug/Release 状態を自動的に付加する場合があります。ネットワークリクエストを受信するために必要な IP アドレスと User-Agent は Aptabase により一時的に処理される場合があります。OmniPDF は、ファイル名、パス、文書内容、OCR テキスト、パスワード、署名、自由入力テキスト、正確なファイルサイズ、正確なページ数、Apple ID、広告識別子、永続的な端末識別子を送信しません。

Aptabase は IP アドレスと User-Agent から、おおまかな地域と毎日変わる仮名識別子を生成します。分析データは Aptabase の欧州連合リージョンで処理・保存され、最長5年間保持される場合があります。お客様の身元には関連付けられず、アプリやウェブサイトをまたぐ追跡、広告、プロファイリング、データブローカーとの共有、販売には使用されません。Aptabase プライバシーポリシーをご覧ください。OmniPDF に広告はなく、アカウントやログインも不要です。

3. ファイル、写真、カメラ

OmniPDF は、PDF、画像、文書の読み込み、写真の選択、カメラによる文書スキャン、ユーザーが選択した場合の結果保存に必要な場合のみアクセスを要求します。

4. PDF 処理

PDF の検出、修正、圧縮、OCR、一括処理、黒塗り、暗号化、解除、ページ編集、署名、透かし、書き出しはすべて端末内で行われます。

OCR を使用する場合、認識されたテキストは端末上で生成され、当社に送信されることはありません。

パスワード関連機能を使用する場合、パスワードは選択した PDF を開く、暗号化する、または解除するために端末内でのみ使用されます。当社がパスワードを取得または保存することはありません。

5. 書き出しファイルとメタデータ

書き出し時、OmniPDF は選択された操作に従って新しい処理済み PDF を作成する場合があります。使用する機能によっては、文書メタデータ、注釈、編集可能な内容、添付ファイル、その他の PDF 情報を削除または変更する場合があります。

テキストの黒塗りやプライバシー情報の削除を使用する場合は、共有前に書き出したファイルを確認してください。

6. App 内課金

任意の購入、保存クレジット、サブスクリプション、有料書き出しは Apple が処理します。当社は支払い情報や Apple ID の詳細を受け取りません。

データ処理に関する補足

端末内の処理と保存

PDF、OCR テキスト、パスワード、署名は端末上で処理し、当方には送信しません。最近使ったファイルは、ローカルコピーと名前・パス・ページ数・サイズを保存する場合があります。履歴の消去で管理対象のコピーを削除します。外部に書き出したファイルは別に管理してください。

限定的な利用分析

Aptabase を使用するアプリは、機能の利用、書き出し、購入結果などの限定的なイベントを自動送信します。一時的なセッション ID、日時、端末モデル、言語、OS とアプリのバージョンなどが含まれる場合があります。サービスは通信に必要な IP アドレスと User-Agent を処理し、おおまかな地域と毎日変わる仮名識別子を算出します。写真や書類の内容は分析に含まれません。

Aptabase のポリシーでは、分析データは最長 5 年間保存される場合があります。永続的な個人識別子がないため、特定の利用者のイベントを探して削除できない場合があります。

Aptabase · プライバシーポリシー

アプリ内購入は Apple が処理します。カード情報や Apple ID は当方に送信されません。サポートへのメールには、メールアドレス、本文、お客様が選んだ添付ファイルが含まれます。

処理と結果のプレビューはアプリ内で利用できます。処理済みファイルの書き出しや共有にはアプリ内購入が必要です。書き出し回数、月額、年額、買い切りプランから選べます。現在のプランと価格はアプリと App Store でご確認ください。
