公開済みポリシーの全文

1. 目的： StillTap は、軽量な静心・マインドフルネスツールです。木魚、数珠、焚香タイマー、シンギングボウルの音、呼吸ガイドなどのシンプルな練習を提供します。

2. データプライバシー： StillTap は個人データを収集、保存、販売、共有しません。アプリは完全なオフライン使用のために設計されており、ネットワーク通信は第 3 項に記載する限定的な匿名利用統計のみです。

3. 匿名の利用統計： 品質向上のため、StillTap はサードパーティサービス Aptabase により匿名の機能利用・購入ファネルイベント（どの練習機能を使ったか、使用時間の幅、ペイウォールを開いたか、購入が完了したか等）を記録します。記録されるのは固定の選択肢と時間帯のみで、練習内容・個人を特定する情報・端末識別子は含まれません。App Store の広告をタップしてインストールした場合、Apple の公式アトリビューション API から広告キーワードや国などのソース情報が返され、広告効果の測定のみに使用されます。いずれの統計もお客様ご個人と紐付けることはできません。システム設定でネットワークアクセスを制限すると、統計の送信を無効化できます。

4. ローカル練習データ： タップ数、数珠の回数、静心時間、連続使用日数、設定、サウンド設定、Pro 状態などの練習記録は、デバイス内にローカル保存されます。

  • 練習データはサーバーにアップロードされません。
  • アカウント登録は不要です。
  • App 外での個人活動を追跡しません。

5. サウンド、触覚フィードバック、通知： StillTap は、ローカルサウンド再生、触覚フィードバック、任意のリマインダーを使用する場合があります。

  • サウンドと触覚フィードバックはデバイス上で処理されます。
  • リマインダーを有効にした場合、ローカル通知のみに使用されます。
  • 通知権限はデバイス設定で管理できます。

6. 医療目的ではありません： StillTap は医療アプリではありません。医療上の助言、診断、治療、セラピーを提供しません。本 App は、リラックス、集中、個人的な静心練習のみを目的としています。

7. サポート： rtx3070757@gmail.com
