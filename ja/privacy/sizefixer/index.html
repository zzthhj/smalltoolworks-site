1. プライバシーの概要

SizeFixer（以下「本アプリ」）は、アップロード用に写真の容量圧縮・形式変換・サイズ調整を行います。写真の処理はすべて端末内で行われます。

製品をより良くし、皆さまにより良いサービスを提供するため、本アプリは限定的な製品操作データを送信します。写真や画像の内容が端末外に出ることはありません。

2. 写真とローカルデータ

写真ライブラリおよびファイルへのアクセスは、以下のみに使用します。

  • ライブラリからの写真選択、または画像ファイルの読み込み
  • ユーザーが選択した場合の、「ファイル」または「写真」への結果保存

圧縮、変換、リサイズ、トリミングはすべて端末内で実行されます。写真がサーバーにアップロードされることはありません。

顔の黒塗り機能は、Apple の Vision フレームワークを使用し、完全に端末内で顔の位置を検出して、その上に黒塗りを描画します。顔データや検出結果が保存または送信されることはありません。

3. 書き出しファイル

書き出し時に、SizeFixer は GPS やカメラ EXIF などの隠しメタデータを出力ファイルから削除する場合があります。端末に書き込まれるのは、ユーザーが保存を選択した画像データのみです。

4. 限定的な利用分析

プライバシー重視の分析サービス Aptabase を使用します。アプリの起動、利用した機能、読み込んだ項目数、処理や書き出しの成否、ペイウォールの操作、購入と復元の結果を記録する場合があります。

写真、画像の内容、ファイル名、画像内で認識された文字、バーコードや QR コードの内容、氏名、メールアドレス、端末の広告識別子（IDFA など）、自由入力テキストは送信しません。

Aptabase の SDK は、一時的なセッション ID、アプリおよびシステムのバージョン、端末モデル、言語／地域などの基本技術情報を送信する場合があります。同サービスは IP アドレスと User-Agent を一時的に処理し、おおまかな地域と日替わりの仮名識別子を生成します。データは Aptabase の EU リージョンで処理され、最長 5 年間保持される場合があります。Aptabase プライバシーポリシーをご覧ください。

App Store の広告をタップしてから本 App をインストールした場合、Apple の公式アトリビューション機能から、広告キャンペーンやキーワード、国・地域などのソース情報が返ることがあります。これらの匿名の数値 ID を購入イベントとともに記録するのは、広告の効果を把握するためのみです。いずれの統計も、お客様ご本人と結び付けることはできません。

5. 広告、追跡、アカウント

本アプリに広告はなく、広告ネットワークとのデータ共有や、他社アプリ・ウェブサイトを横断した追跡も行いません。アカウントやログインは不要です。

6. App 内課金

保存クレジットとサブスクリプションは Apple が処理します。当社はカード情報や Apple ID を受け取らず、機能のロック解除に必要な購入状態と、プラン区分や購入結果などの限定的な分析データのみを受け取ります。

データ処理に関する補足

端末内の処理と保存

画像編集と顔のマスキング検出は端末上で処理します。必要に応じてメタデータを読み取り・削除しますが、利用分析には送りません。書き出した画像はお客様が管理します。

限定的な利用分析

Aptabase を使用するアプリは、機能の利用、書き出し、購入結果などの限定的なイベントを自動送信します。一時的なセッション ID、日時、端末モデル、言語、OS とアプリのバージョンなどが含まれる場合があります。サービスは通信に必要な IP アドレスと User-Agent を処理し、おおまかな地域と毎日変わる仮名識別子を算出します。写真や書類の内容は分析に含まれません。

Aptabase のポリシーでは、分析データは最長 5 年間保存される場合があります。永続的な個人識別子がないため、特定の利用者のイベントを探して削除できない場合があります。

Aptabase · プライバシーポリシー

このアプリは Apple AdServices で App Store 広告からのインストール元を取得します。キャンペーン、キーワード ID、国や地域などの限定的な情報を利用分析に用います。写真は送信しません。

アプリ内購入は Apple が処理します。カード情報や Apple ID は当方に送信されません。サポートへのメールには、メールアドレス、本文、お客様が選んだ添付ファイルが含まれます。
