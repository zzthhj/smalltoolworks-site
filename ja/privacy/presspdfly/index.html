PressPDFly · プライバシーポリシー

PDF は端末内で圧縮し、文書の内容を処理のためにアップロードしません。限定的な利用分析、購入、Google AdMob の広告には通信を利用する場合があります。

2026-10-28

適用範囲と端末内のファイル

PressPDFly は1つずつ PDF を圧縮します。読み込んだ文書、パスワード、ページ内容、結果は端末内で処理し、当方にアップロードしません。作業用ファイルや設定は端末に保存される場合があります。ファイル、他のアプリ、バックアップに書き出したコピーは別途管理してください。

ファイルへのアクセス

システムのファイル選択画面で選んだ文書を読み込み、処理するためにアクセスします。アカウントは不要です。

限定的な利用分析

Aptabase の EU リージョンを利用します。起動、読み込み、圧縮・書き出しの結果、購入結果について固定の分類と概略の範囲を送信します。PDF 内容、ファイル名、パス、パスワード、正確なサイズやページ数、自由入力、元のエラーは送りません。

分析の技術情報

SDK は時刻、一時的なセッション ID、言語、アプリ・ビルド・OS バージョン、端末モデル、Debug/Release 状態を付加する場合があります。Aptabase は IP アドレスと User-Agent を処理し、おおまかな地域と日ごとに変わる仮名識別子を生成する場合があります。同社の方針では最大5年間の保持が示されています。永続的な個人識別子がないため、個別イベントの特定や削除が難しい場合があります。専用の分析停止設定はありません。

広告

PressPDFly は無料で利用でき、Google AdMob の広告によって支えられています。広告のリクエスト、配信、計測のため、Google と広告パートナーは端末情報、端末識別子（利用可能な場合は広告識別子を含む）、IP アドレスから推定したおおよその地域、広告の操作データを収集する場合があります。当社は Apple の ATT（トラッキングの許可）を要求していないため、広告識別子がアプリやウェブサイトをまたぐトラッキングに使われることはありません。必要な地域（欧州経済領域、英国、スイスなど）では Google の User Messaging Platform を通じて同意を求めます。同意はアプリの「設定 → 広告のプライバシー設定」でいつでも変更・撤回できます。Google は広告データを同社のプライバシーポリシーに従って処理します。PDF の内容、ファイル名、圧縮結果が広告パートナーに共有されることはありません。

購入

1回の書き出しと永久購入は Apple が処理します。1回の購入ではその1回の書き出しで広告が表示されず、永久購入では広告が表示されなくなります。アプリは取引と権利を読み取り、書き出しの解除に必要な残数と取引記録を端末に保存します。カード情報や Apple ID は受け取りません。購入結果の限定的な分類を分析に使用します。

保持と選択

文書処理は端末内ですが、分析、購入、広告には通信を利用する場合があります。広告データは Google のポリシーに従って保持されます。

サポートと変更

メールで連絡すると、返信のためにメールアドレス、本文、任意の添付を受け取ります。プライバシーの質問やサポートメールの削除依頼はご連絡ください。データ処理が変わる場合はこの方針を更新します。
